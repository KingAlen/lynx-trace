# @byted-lynx/lynx-agent

An npm package for trace analysis.

## Installation

```bash
npm install @byted-lynx/lynx-agent
```

## Usage

```javascript
const { koaApp, trace_analysis } = require('@byted-lynx/lynx-agent');
```

## Development

### Build

```bash
npm run build
```

### Development Mode

```bash
npm run dev
```
